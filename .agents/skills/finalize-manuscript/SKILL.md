# Finalize Manuscript

Use any priorities supplied with the invocation.

1. Resolve the repository root and run `./sync-state.sh`.
2. Confirm which chapter files exist and identify incomplete, duplicate, missing, or unusually short files.
3. Read `.agents/roles/continuity-editor.md` and perform or delegate a manuscript-wide continuity audit.
4. Read `.agents/roles/smart-planner.md` and perform or delegate structural and pacing review.
5. Use the `character-developer` role when arc resolution or knowledge state is uncertain.
6. Produce a prioritized revision plan before making broad edits.
7. If the user requested edits, apply them in bounded passes and recheck affected continuity.
8. Separate blocking issues, important revisions, optional polish, and material that appears complete.
9. Do not declare the manuscript publication-ready solely because automated checks pass.
